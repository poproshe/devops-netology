# Домашнее задание «Работа с ветками в Git»

## Что было сделано:
1. **Подготовка:** Создана папка `branching` с файлами `merge.sh` и `rebase.sh`. Сделан общий коммит.
2. **Ветка `git-merge`:** Создана от `main`. В ней сделаны два коммита, меняющие логику `merge.sh` (`$*` на `$@`, затем цикл `while` с `shift`). Ветка влита в `main` без конфликтов.
3. **Изменения в `main`:** В `rebase.sh` добавлена строка разделителя `=====`. Сделан коммит.
4. **Ветка `git-rebase`:** Создана из прошлого (до изменения `main`), от коммита `prepare for merge and rebase`. Сделаны два коммита, меняющие `rebase.sh`.
5. **Rebase:** Выполнен интерактивный `rebase -i main` с последующим объединением (squash) двух коммитов в один. Ветка влита в `main`.
6. Все изменения запушены в GitHub и GitLab. Схема коммитов (Network) наглядно показывает ответвление и слияние обеих веток.
